🚀 Task Board - Tablero Kanban

Aplicación web fullstack para gestión de tareas estilo Trello.

📦 Stack
• Backend: ASP.NET Core 10 Web API
• Frontend: Blazor WebAssembly
• Base de datos: SQLite (Entity Framework Core)
• Lenguaje: C#

✨ Funcionalidades
• CRUD completo de columnas y tarjetas
• Drag & drop para reordenar y mover tarjetas
• 8 etiquetas de color personalizables
• Fechas de vencimiento con indicadores de estado
• Subtareas y comentarios por tarjeta
• Sistema de deshacer (Ctrl+Z) con undo automático
• Atajos de teclado (N nueva columna, E editar, Esc cerrar)
• Búsqueda y filtros avanzados (por etiqueta y fecha)
• Toasts de notificación con acciones de deshacer
• Confirmaciones personalizadas para eliminar
• Diseño responsive (desktop y móvil)
• Validación de formularios con feedback visual

🛠️ Ejecución
• Backend: dotnet run (puerto 5032)
• Frontend: dotnet run (puerto 5048)
